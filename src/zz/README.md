# `zz`: C utilities

> Yes, there is a `zz` in it's own repo but this is the one that is up to date.

Gives you stuff like dynamic list/arrays and hash maps.

Named `zz` because implementing that stuff per project will make you go zzzzzzzzz.

Inspired by stuff found [here](https://github.com/RealNeGate/Cuik/tree/master/common).
