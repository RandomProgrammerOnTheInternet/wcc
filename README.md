# `wcc` - the `Wonderful C compiler`
C Compiler, largely based on `chibicc` (used as a tutorial).

Currently it implements Calculator Number Lang. Single letter variables, simple expressions, semicolons, etc.

I plan to also add a proper IR optimizer & codegen after I get far enough.

## Build

```sh
$ make
```

## Test

```sh
$ make test
```

## Help

```sh
$ make help  
```
